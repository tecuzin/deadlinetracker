## [1.0.0] - 2025-12-12

### Added
- Statistics screen with comprehensive analytics
  - Overview cards showing total, active, overdue, and critical deadlines
  - Status distribution with visual progress bars
  - Time analysis with average time remaining
  - Upcoming deadlines list (next 7 days)
  - Recent activity tracker
- Bottom navigation bar for easy screen switching
- Dynamic app bar title based on selected tab
- Empty state handling for statistics screen

### Changed
- Reorganized home screen to use bottom navigation
- Improved UI consistency across screens
- Updated README with statistics feature documentation

### Fixed
- Navigation flow improvements

## [0.1.0] - Initial Release

### Added
- Basic deadline tracking functionality
- Add, view, and delete deadlines
- Real-time countdown display
- Overdue deadline highlighting
- Data table view with sorting
- Form validation
- Material Design 3 UI
- Provider-based state management
